Feature plugin

Presence API

See who is logged in, which admin screen they are on, and which posts they are editing.

Try it in Playground Download the plugin

Requires WordPress 7.0 and PHP 7.4.

“You log into your WordPress, I see oh Matias is moderating some comments, Lynn is on the dashboard maybe reading some news… that idea of like you log in and you can kind of see the neighborhood of like who else is also there.”

Matt Mullenweg, WordPress 7.0 planning session

Who else is here

Faces in the admin bar show who is online and who is on this page, and an Active Posts widget on the dashboard groups them by post. Each feature has a switch on Settings > Presence API.

Editors on the Posts list

An Editors column shows who has each post open.

Online now, on the Users list

An Online view filters the Users list to the people online right now.

A notice when your screen goes stale

When someone else saves a screen you have open, such as Settings or a post, a notice tells you it changed.

Network Admin, too

On multisite, a Who's Online widget lists the busiest sites and how many people are on each.

  • Synced patterns A notice on a synced pattern in the block editor while someone else edits the pattern itself.
  • Post locks Kept in the presence table instead of post meta, so holding a lock no longer makes cached post queries stale.
  • AI agents Labelled in the admin bar, the Active Posts widget and the Editors column, once a plugin such as Agent Users marks them.

Built for every host

Tracking who is where takes frequent writes, and in post meta or options those writes clear caches across the whole site (#64696). Presence API writes to its own table instead, through the Heartbeat API WordPress already runs.

  • One table wp_presence, with a unique key on room and client.
  • 150 seconds How long a row counts as present without a fresh heartbeat.
  • No extra services No object cache, no WebSockets. Anything a host adds is a bonus.

For developers

PHP functions, REST endpoints, WP-CLI commands, filters and room conventions are documented in the GitHub repository.

PHP

// Put this client in a post's room.
wp_set_presence(
	'postType/post:42',
	$client_id,
	array( 'screen' => 'edit' ),
	array( 'user_id' => get_current_user_id() )
);

// Read who is in it.
$entries = wp_get_presence( 'postType/post:42' );

REST

GET /wp-presence/v1/presence?room=admin/online

WP-CLI

wp presence summary
