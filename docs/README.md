# Presence API

Presence API records who is where in WordPress: who is logged in, which admin screen they are on, and which posts they are editing.

- [Learn presence](learn/README.md) builds a working model of the system in ten short lessons.
- The [README on GitHub](https://github.com/WordPress/presence-api#readme) is the full reference for functions, hooks, REST routes and WP-CLI commands.
