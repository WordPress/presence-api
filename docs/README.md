# Presence API

Presence API records who is where in WordPress: who is logged in, which admin screen they are on, and which posts they are editing.

| To | Go to |
| --- | --- |
| Try it without installing anything | [Presence Scenes in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/WordPress/presence-api/main/blueprint-scenes.json), which plays two people editing one post |
| Understand how it works | [Learn presence](learn/README.md), ten short lessons |
| Look up a function, hook, route or command | The [README on GitHub](https://github.com/WordPress/presence-api#readme) |
| Report what you found | [Issues on GitHub](https://github.com/WordPress/presence-api/issues) |
